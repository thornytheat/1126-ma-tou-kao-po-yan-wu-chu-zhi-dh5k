# 码头靠泊延误处置 · 字段与计算

本项目使用确定性模拟业务数据。所有时间均以业务台账指定粒度解析。

## 报港与作业数据

报港通知有航次、IMO 号、所属航线、版次、发布时间、预计到港、吃水、箱量、冷藏箱量、船长及申报来源。按航次与版次确定快照，同版按人签审核级别取证，同权同版矛盾隔离。

潮汐预报采用营运日分钟，每 15 分钟采样。发布不晚于截面。预报端点的最浅水深加图载深度，减去实报吃水及净余要求后应非负；连续安全格合并，维修时段和船体长度限制单独生效。

## 模型与运营裁决

已结案记录的箱量按岸桥数平摊，另外用冷藏占比、吃水和堆场占用四个变量建立中位数绝对偏差缩放。按加权绝对距离选近邻并以距离倒数取加权中位数与上界。在候泊历史上拟合带 L2 惩罚的二元逻辑模型，使用后续留出按分桶先验做平滑。超出训练域需要人工复核。

允许配额表示可安排的靠泊航次数，默认 7，按紧急、冷藏、承诺上限和航次键遴选。任何分派均另行重验泊位、潮位和会议资源。等待保障费以每冷藏箱每小时分计量，逐行向上取整。
